# Yusiraen Clipper

Kick yayınlarının sohbetini kaydeder, sohbetin patladığı anları bulur ve otomatik klip alır.

Bu depo yalnızca uygulamanın **kurulum dosyalarını** (Releases) barındırır. Uygulama yeni sürümleri buradan kendisi kontrol eder ve günceller.

**İndir:** [Releases](https://github.com/Snowy2729/yusiraen-clipper/releases/latest) → `Yusiraen-Clipper-Kurulum.exe`
