YouTube bağlantısı

Bağlı değil
Nasıl bağlarım? (bir kerelik, ücretsiz, ~5 dakika)
  1. console.cloud.google.com adresine YouTube kanalının olduğu Google hesabıyla gir, üstten Yeni proje oluştur (adı: Yusiraen Clipper).
  2. Sol menü → API'ler ve Hizmetler → Kitaplık: YouTube Data API v3 ve YouTube Analytics API'yi bulup Etkinleştir.
  3. OAuth izin ekranı (Google Auth Platform): Kullanıcı türü Harici, uygulama adı Yusiraen Clipper, e-postanı yaz. Kitle / Test kullanıcıları kısmına kendi Gmail'ini ekle.
  4. Yayınlama durumunu Üretime gönder (doğrulama gerekmez; yoksa bağlantı 7 günde bir düşer). Girişte "Google bu uygulamayı doğrulamadı" uyarısı çıkarsa Gelişmiş → Devam et.
  5. Kimlik bilgileri → Kimlik bilgisi oluştur → OAuth istemci kimliği, uygulama türü Masaüstü uygulaması. Çıkan Client ID ve Client Secret'ı aşağıya yapıştır.
