Kick uygulaması (bir kerelik kurulum)

Moderatör doğrulaması (Kick ile giriş) için bir Kick geliştirici uygulaması gerekir. Yalnızca bir kişinin (ör. sen) oluşturması yeterli; diğer modlara ekip kodunu verirsin.

Nasıl oluşturulur? (ücretsiz, ~3 dakika)
  1. kick.com'da hesabına gir → sağ üst profil → Ayarlar → Geliştirici (kick.com/settings/developer).
  2. Create App / Uygulama oluştur. Ad: Yusiraen Mod.
  3. Redirect URL alanına tam olarak şunu yaz:
  4. İzinlerden sadece Read user information (kullanıcı bilgisini okuma) yeterli. Uygulama başka hiçbir şeye erişmez.
  5. Oluşan Client ID ve Client Secret'ı aşağıya yapıştır, Kaydet.
Ekip kodu
Diğer modlar Client ID/Secret uğraşmadan bu kodla kurar. Sadece güvendiğin kişilere ver.
