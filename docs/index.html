Yusiraen Clipper

Kick yayınlarından klip çıkarıp düzenleyen ve kendi YouTube kanalına yükleyen ücretsiz Windows uygulaması.

Windows için indir

Ne yapar?
  • Canlı Kick yayınının sohbetini kaydeder, sohbetin hareketlendiği anları bulur ve klip olarak keser.
  • Klipleri dikey (9:16) düzenler, otomatik Türkçe altyazı ekler (altyazı tamamen bilgisayarında üretilir).
  • İsteğe bağlı: Kullanıcı kendi YouTube hesabını bağlarsa, hazırladığı klibi kendi kanalına yükler ve kanalının istatistiklerini uygulamada gösterir.
Google / YouTube verileri
Uygulama YouTube API Hizmetleri'ni kullanır. Hesap bağlantısı yalnızca kullanıcı isterse yapılır; veriler kullanıcının bilgisayarında kalır, hiçbir sunucuya gönderilmez. Ayrıntılar: Gizlilik Politikası.

English

Yusiraen Clipper is a free Windows desktop application that records the chat of a live Kick stream, finds highlight moments, cuts them into clips, lets the user edit them (vertical 9:16 layout, locally generated Turkish subtitles) and — only if the user chooses to connect their own YouTube account — uploads the user's clips to the user's own YouTube channel and shows that channel's statistics inside the app.

The app uses YouTube API Services. All data stays on the user's own computer; the developer runs no servers and receives no user data. See the Privacy Policy and Terms of Service.
